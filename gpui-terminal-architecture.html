Desktop architecture · MVP

Rust + GPUI terminal client

Embedded SSH with Russh; no system SSH executable required.

UI stays responsive

Network, PTY, and database I/O run off the UI thread. Coalesce redraws, not terminal bytes.

Typed connection events

The backend reports connection stages and errors, and sends host-key and authentication prompts to GPUI separately from terminal output.

The app owns trust

Verify the server before authenticating. Confirm unknown fingerprints, block changed keys, and never persist passwords or raw terminal output.

MVP boundary: Windows OS, no cloud service, no SFTP, no automatic command replay.
